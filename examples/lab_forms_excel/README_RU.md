# Бланки Excel для TableScan Local

Три редактируемые книги: Von Frey, Plantar и Staircase. По умолчанию — 20 животных. Заголовки слева голубые, справа персиковые. Notes расширен. В первом столбце ID автоматически вычисляется порядковый номер. На бумаге остаются название теста, Date, Session, Operator и таблица.

## Как изменить число животных

1. Откройте нужный XLSX и сохраните свою копию.
2. Чтобы добавить строки, выделите нужное количество **целых строк внутри таблицы** по их номерам слева и выберите в верхнем меню Excel **Вставка → Строки**. Например, выделение строк листа 17–26 и вставка даёт 30 животных вместо 20. Нумерация ID и оформление продолжаются автоматически.
3. Чтобы уменьшить число животных, удалите лишние **строки листа с данными** через меню Excel. Очистка содержимого ячеек не уменьшает число строк таблицы.
4. Сохраните первые шесть строк листа, названия и порядок столбцов. Высота всех строк с животными должна быть одинаковой. Не объединяйте ячейки внутри таблицы.

## Печать и заполнение

В книгах задана альбомная A4, поля 10 мм, размещение на одной странице по ширине и высоте. Перед печатью проверьте предварительный просмотр: вся таблица и её внешние границы должны быть видны. При 30–40 животных строки на A4 становятся мельче из-за масштаба печати.

Заполняйте бумагу вручную. Date — дата, Session — обозначение сессии; эти два поля обязательны для экспорта. Operator необязателен. Пустое измерение означает пропуск, а не ноль. В Notes можно писать свободный текст. Правила колонок доступны в примечаниях Excel и в шаблоне TableScan; они не печатаются.

## Сканирование, анализ и экспорт

1. Отсканируйте целый лист, сохранив шапку и все линии таблицы. Подходят цветные и чёрно-белые изображения. Сильно перекошенную страницу сначала выровняйте в программе.
2. В TableScan Local 0.7.15 выберите шаблон **Von Frey**, **Plantar** или **Staircase**. Все три доступны с первого запуска приложения. На другом компьютере импортируйте одноимённый JSON из папки `templates`.
3. Оставьте включённой автоматическую подгонку числа строк и запустите распознавание. Для 5, 10, 15, 20, 30 и 40 животных используется один и тот же шаблон соответствующего теста. Правила продлеваются на все найденные строки.
4. Проверьте распознанные значения и замечания программы. В особенности проверьте рукописные десятичные разделители, Notes и Operator.
5. Выполните расширенный экспорт XLSX. Лист **«Исходная таблица» / «Original table»** содержит привычную матрицу: одна строка на животное. Лист **Data** дополнительно сохраняет Date, Session, Operator, тест, сторону и измерение. Компактный экспорт содержит только матрицу, без дополнительных полей.

Экспорт создаёт отдельную заполненную книгу. Исходный пустой бланк остаётся шаблоном для дальнейшей печати.

Автоподгонка рассчитана на изменение количества одинаковых строк при сохранении столбцов. Произвольная перестановка столбцов или разная высота строк требуют изменения шаблона. Страницы с разным числом строк загружайте отдельными файлами: текущая версия использует одну общую сетку внутри многостраничного задания.

## Состав тестов

| Бланк | Измерения |
|---|---|
| Von Frey | L1–L5, R1–R5; неотрицательные числа |
| Plantar | L1–L5, R1–R5; неотрицательные числа |
| Staircase | L1–L7, L drop, R1–R7, R drop; неотрицательные целые |
